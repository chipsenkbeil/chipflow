## What shipped

KF-222 (HIGH): the Pomodoro legend footer rendered on every board; generic
KanbanFlow shows no footer unless the board's "Color legend" toggle is ON.
The fix reuses the existing `legend_visible` board-config key (from KF-183):
the footer is server-rendered only when the toggle is ON, showing one labeled
segment per enabled board color (custom names); when OFF, zero footer markup
is emitted. New boards default OFF. Existing boards are backfilled to visible
exactly once (explicit OFF preserved) via a lazy migration in `db.rs`.

Files changed: `agents.md`, `src/db.rs`, `src/routes.rs`, `static/app.js`,
`static/style.css`, `templates/board.html`, plus durable state
(`.dev/kf-parity-defects.md`, `.dev/phase-log.md`, builder/verifier reports,
screenshots, golden-master fixture + spec).
