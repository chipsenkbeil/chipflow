## Implementation (2 edits, src/routes.rs)

- New `format_relative_day(rfc3339: &str)`: parses RFC3339, converts to Local; if `date_naive()` equals today's local `date_naive()` → `"Today"`, else `format("%b %d")`; parse failure → input unchanged (same fallback shape as `format_day`).
- task_modal: `let created_short = format_relative_day(&row.created_at);` (was `format_day`).
- New unit test `format_relative_day_is_today_for_same_calendar_day`: now → "Today"; today 00:00:01 → "Today"; yesterday → `%b %d`; garbage input → passthrough. Imported into tests' `use super::{...}`.
