# KanbanFlow card context menu (live, 2026-10-16, Golden Master board JYv2f3u)

Observed in the owner's logged-in Chrome on a test board; nothing was left changed
(In Review was reordered by "Move to bottom" four times and ends in its original
order: Add two-factor authentication, Rewrite user profile page, Improve
dashboard load time, Fix date formatting in reports).

Right-click a card -> menu items in order, each with an icon:
Start timer, Move ▸, Color ▸, Assign members, Copy here, Task URL, Delete.

Move ▸ submenu, in order, each with an icon:
1. Move right
2. Move to bottom — moves the card to the BOTTOM OF ITS OWN COLUMN (proven:
   "Add two-factor authentication" went from first to last in In Review, same x).
3. Move advanced — opens a small "Move task" popover anchored at the card, with a
   title "Move task", an × close button, a "Board" select (current board), a
   "Column" select (current column) and a green full-width "Move" button.
   It is NOT an inline list of columns inside the submenu.
