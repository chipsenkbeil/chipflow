# KF-229 Builder Report — 2026-10-01 02:25 UTC

## Defect
**KF-229** [MEDIUM | Timer]: the board-bar timer pill never showed a countdown or
play/stop glyph. `TimerUI.renderPill` (static/app.js ~2375) writes the countdown
text and play/stop glyph into `#timer-pill-icon` / `#timer-pill-time` child
elements, but KF-209 replaced the pill's contents with a bare clock SVG — those
child elements no longer existed in templates/board.html. The writes are
null-guarded, so they silently did nothing.

## Fix (templates/board.html only — no JS changes)
Restored the pill's inner spans in the KF-209 right-side position:

```html
<button type="button" id="timer-pill" class="board-bar-btn timer-pill" title="Timer" aria-label="Timer" aria-haspopup="dialog">
  <span id="timer-pill-icon" class="timer-pill-icon timer-pill-play" aria-hidden="true">&#9654;</span>
  <span id="timer-pill-time" aria-hidden="true">--:--</span>
  <span class="timer-pill-chevron" aria-hidden="true">&#x25BE;</span>
</button>
```

Rationale: `renderPill` was written for exactly this markup (glyph + time +
chevron, the KF-098 pill states). KanbanFlow's actual chip shows the live
countdown text + dropdown arrow (video evidence v3-e022 "25:00" idle chip,
v9-e002 "00:02" running stopwatch chip) — the restored markup matches that
while keeping KF-209's right-side placement. The `timer-pill` class re-enables
the existing CSS (`.timer-pill`, `.timer-pill.running`, play/stop colors).
No JavaScript changes were needed.
