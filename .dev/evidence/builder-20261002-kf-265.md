# Builder evidence — KF-265 (2026-10-02)

## Defect
"Add subtask..." in the task-detail modal's Subtasks section rendered as a boxed
text input (1px border, white-ish fill). KanbanFlow (GM-085-modal-open.png,
1919x998 @DPR1) renders it as a plain unstyled text row: no border, transparent
background, gray (#666) text aligned with the subtask-name column.

## Golden measurements (GM-085-modal-open.png, direct pixel sampling)
- Modal body bg: rgb(255,234,194) (#FFEAC2) — sampled at multiple empty areas.
  NOTE: the planner's contract said "modal cream rgb(255,249,237)"; direct sampling
  of the golden master gives (255,234,194). The input is transparent so it inherits
  the modal bg either way; the candidate's modal bg matches the golden exactly.
- Placeholder "Add subtask..." glyphs: y 503-513, text left x≈717-718;
  subtask-name "Write integration tests" text left x≈717 (Δ ≤ 1px — same column).
  Placeholder ends in three separate dots ("..."), matching our template string.
- Placeholder darkest glyph pixel: (104,100,92) ≈ #666666.
- Row pitch between name rows and the add row: 33px, text vertically centered.
- Vertical scan across the add row at left/right edges: 0 border pixels.

## Approach (CSS-only, static/style.css)
- `.tm-subtask-addrow input`: `border: none; border-radius: 0; background: transparent;
  color: #666;` plus `input::placeholder { color:#666; opacity:1; }`.
- Left alignment: input `padding-left: calc(1.9rem + 7px)` = 37.4px, exactly the
  `.tm-subtask-name` text offset (row pad 6.4px + checkbox 16px + checkbox UA
  margins 4px+3px + flex gap 8px = 37.4px). The 7px UA-margin term was found by
  DOM measurement — CSS arithmetic alone (1.9rem) under-aligned by 7px.
- Height-preserving: old 1px top/bottom borders folded into vertical padding
  (`calc(0.45rem + 1px)`), so the input's outer height is byte-identical
  (34.375px) and nothing below the row moves.
- Focus: `outline: none; border: none; background: transparent` (KanbanFlow shows
  only a blinking caret; caret inherits the #666 text color).
- Out of scope preserved: subtask rows, ⋮ handle menu (KF-264), "N / M" header
  (KF-262), Enter-to-create wiring in app.js (untouched).
