## 1. Diff review (uncommitted changes on master)

Reviewed `git diff` for all four files:

- **`templates/board.html`**: `#column-menu` contains exactly three buttons in
  order — `Edit`, `Collapse` (`data-col-act="collapse"`), `Show details`
  (`data-col-act="details"`). All remnants of the old 6-item menu are gone:
  `Move left`, `Move right`, `Add to left`, `Add to right`, `Delete` removed
  from markup. The old `#column-details-popup` structure was reworked to a
  `.details-head` row (bold `Column:` title + × close button) and a
  `Task count:` body row. Collapsed `th` renders a dedicated strip:
  `.columnHeader-countBadge` (with `--over` modifier when `col.over_limit`),
  `.columnHeader-overdue` ("N overdue task(s)") when `overdue_count > 0`, and
  `.columnHeader-name`; `th` carries `title="{name} / Click to expand"` when
  collapsed. The hidden ⋮ button (`.columnHeader-menu { display: none; }` in
  CSS, unchanged) keeps the menu right-click-only per KF-038 — verified at
  runtime that left-click does not open the menu.
- **`static/app.js`**: menu click handler now dispatches only
  `edit` → `openEditColumnDialog`, `collapse` → `toggleColumnCollapsed`,
  `details` → `showColumnDetails`. Old handlers (`moveColumnBy`,
  `openAddColumnDialog`, `deleteColumn`) no longer referenced from the column
  menu. `toggleColumnCollapsed` PATCHes `/api/columns/{id}` with
  `{collapsed: bool}` then reloads. The Collapse item label is set to
  `Expand`/`Collapse` from `th.dataset.collapsed` at menu-open time.
  `showColumnDetails` fills `details-col-name`/`details-col-count` from
  `data-column-name`/`data-task-count` and positions the popover below the
  header via `placePopup`. The × button hides it. A click handler on
  `#column-headers-row` expands any `.columnHeader--collapsed` strip on
  left-click (right-click still opens the menu; clicks on buttons excluded).
- **`static/style.css`**: `.columnHeader--collapsed` is now a 22px white
  strip (`width: 22px; max-width: 22px; background: #fff`), superseding the old
  48px gray band. Count badge dark `#1f2937`, red only via
  `.columnHeader-countBadge--over { color: var(--danger) }` (`--danger:
  #dc2626`). Overdue label red, `writing-mode: vertical-rl`,
  `white-space: nowrap`. Name `writing-mode: vertical-rl` +
  `transform: rotate(180deg)` (bottom-to-top), `text-transform: uppercase`.
  `.board-cell--collapsed` background changed to white to match.
  Details popover head styles added (bold title, × button).
- **`src/routes.rs`**: `ColumnHead` gained `overdue_count: usize`, computed
  with the identical rule as `TaskView::due_overdue` (RFC3339 parse,
  `dt.with_timezone(&Local) < Local::now()`, `completed_at.is_none()`).
  Verified the two code paths side by side — same predicate.

No API surface changes (`ColumnHead` is a template struct, not an API view);
`agents.md`/`agents.json`/OpenAPI unaffected. No other files touched.

## Notes (non-blocking)

- The builder's `35/35` claim was its own harness; the verifier's
  independent battery is `34/34` on a different check set. Four transient
  failures in an early verifier harness iteration were traced to
  navigation-race bugs in the *harness* (checking the DOM before
  `location.reload()` completed), not product bugs — fixed by wrapping
  collapse/toggle clicks in `expect_navigation(wait_until="load")`.

  list view (returns `None`); collapse persistence was verified at the UI
  and server-restart level instead. Not a KF-223 defect, but the flag is
  only observable via the rendered board page.

  port confirmed free). No other ports touched. Nothing committed; the
