## Implementation

- `templates/_manual_time_dialog.html` — replaced the two `.dlg-toggle`
  buttons with `<label class="check-label"><input type="checkbox"
  id="mt-labels-check"> Add labels</label>` + labels div, then the comment

- `templates/board.html` — same change in the edit-entry dialog (`ee-` ids).
- `static/style.css` — removed the now-unused `.dlg-toggle` rules; added a
  scoped `#manual-time-overlay .check-label, #edit-entry-overlay .check-label
  { margin-bottom: 0.35rem; }` spacing rule (reuses the existing `.check-label`
  convention from the column dialog).
- `static/app.js`
  - `ManualTime.open` / `EditEntry.open`: checkbox reset instead of toggle
    textContent. EditEntry now expands + checks the comment/labels sections
    when the entry being edited already has a note/labels (matches the
    checkbox-expander semantics; previously the note was set but hidden).
  - `toggleComment` (both dialogs): visibility follows the checkbox `change`
    event; focus moves into the revealed input.
  - `makeLabelEditor` (`mt`/`ee`): `set` checks the labels box when labels
    exist; `reset` unchecks; `toggle` syncs the section from checkbox state.
  - Wiring: `click` on the old toggle buttons → `change` on the new
    checkboxes (both in `initEntryEdit` and `initTaskExtras`).
