     target board's columns and resolves the target column by same-name match, else the

     same-board moves, null on cross-board (exactly the old semantics: the old lane select
     reset to empty on board change); position = card count in the target column's list for

     All `#mt-col/#mt-lane/#mt-pos` element references removed — those elements no longer exist.

   exact static-label typography (text-source master gives no pixel spec).
