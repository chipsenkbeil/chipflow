Built 2026-09-30 17:54 CDT (22:54 UTC) by the KF-224 builder subagent.

## What was built

KanbanFlow-exact card layout in `templates/task_card.html` + supporting
changes:

1. **Icon row** (top of card, under the title): document / calendar /
   checklist / speech-bubble icons in KanbanFlow's order, then a clock
   glyph + time text, then the assignee avatar right-aligned. Each icon
   renders only for a feature the task HAS (never greyed out). Tooltips
   match KanbanFlow verbatim ("Has description. Click to expand or
   collapse.", "Has due dates. Click to expand or collapse.", "Has
   subtasks. Click to expand or collapse.", "Has comments. Click to view
   comments."). The icon row is additionally gated by the existing
   `TaskCardDisplay` column config (KF-043) — KanbanFlow's own default
   hides description/subtasks/labels, and a test
   (`card_display_defaults_match_kanbanflow`) pins that default.
2. **Section expand/collapse**: each icon toggles its card section;
   state persists per task in `localStorage` (`chipflow.cardsec.<id>`,
   defaults description=collapsed, duedates/subtasks=expanded, matching
   the reference screenshot). Applied on load, on htmx swaps, and on
   quick-add inserts. Comments icon opens the task modal.
3. **Due line**: `Due: <strong>Friday 5:00 PM</strong>` (+ `<span
   class="task-dueDateColumn">(Done)</span>` when the due-date item is
   checked). Within ±7 days → weekday form; farther → `20 November 5:00
   PM`. Dotted divider above, tinted with the card color via the
   existing `taskColorVars-*` class. New `due_done` field on `TaskRow`
   (serde default, no migration): set via PATCH `/api/tasks/{id}`
   `{"due_done": true}` or the new "Mark as done" checkbox in the
   due-date dialog; resets when the due date itself changes and when the
   due date is cleared.
4. **Inline subtasks**: `<ul class="subTasks">` with custom square
   checkboxes (undone first, first 2 visible, rest under
   `card-sub-extra`), summary `2 hidden (2 done)` with title "Click to
   expand subtasks" that expands the list. Checkboxes toggle live via
   PATCH `/api/tasks/{id}/subtasks/{sub_id}` and recompute the summary
   from the card's `data-subtasks-total`/`data-subtasks-done`.
5. **Time readout**: `2h 30m / 8h` (spent / estimate), `0h / 4h`, or
   spent-only `45m`; title "Time spent / Time estimate".

Dropped from the card: old due chip, old time/pomodoro spans, "✓
completed" chip. Kept: labels chips, created/added dates (config-gated),
`<span class="card-live" hidden>` (timer live-tick JS targets it).
