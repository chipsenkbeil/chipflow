## What was built

Reproduced KanbanFlow's column header menu, column collapse strip, and column details popover:

1. **Column menu** (`templates/board.html`, `static/app.js`): right-click on a column header now shows exactly three items — **Edit / Collapse / Show details**. The Collapse item label dynamically reads "Expand" when the column is already collapsed.

2. **Collapse / expand** (`static/app.js`): Collapse sends `PATCH /api/columns/{id}` with `{"collapsed": true}`, then reloads the page (KanbanFlow behavior). Expand works the same way in reverse. Left-click on a collapsed strip expands the column (right-click still opens the menu).

3. **Show details popover** (`templates/board.html`, `static/app.js`, `static/style.css`): `#column-details-popup` reworked to spec — bold "Column: {name}" title row with × close button, body shows "Task count: {n}". Popover positions below the column header via the existing `placePopup` helper; × dismisses it.

4. **Collapsed strip** (`templates/board.html`, `static/style.css`): collapsed `th` renders a dedicated white strip, 22px wide, containing:
   - Count badge (bold; red `rgb(220, 38, 38)` only when WIP limit exceeded, dark otherwise; tooltip "Task count: N / Click to expand")
   - Overdue indicator when the column has overdue tasks: red vertical "N overdue task(s)" label, tooltip "Overdue tasks: N / Total tasks: M / Click to expand"
   - Column name in `writing-mode: vertical-rl` + `rotate(180deg)` (bottom-to-top), uppercase

5. **Overdue count** (`src/routes.rs`): added `overdue_count: usize` to `ColumnHead`, computed per column with the same rule as `TaskView::due_overdue` (due_at parses as RFC3339, `dt < Local::now()`, `completed_at.is_none()`).

Two issues found and fixed during verification:

2. **Reload detection (16:30 CDT):** `Location.prototype.reload` cannot be stubbed in Chromium (`window.location.reload === Location.prototype.reload` is `False`; `Object.defineProperty` throws). (Also learned: `threading.Event.wait()` on the main thread freezes Playwright's event loop — the PATCH was only dispatched after the 5s timeout.)
3. **Overdue label wrapping (16:33 CDT):** "1 overdue task" wrapped letter-by-letter in the 22px strip; changed to `writing-mode: vertical-rl` + `white-space: nowrap` for a clean vertical red label.
