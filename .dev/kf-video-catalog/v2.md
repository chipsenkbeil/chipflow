## Distinct UI surfaces / states

### S1 — Chat conversation view with in-progress typing (v2-e001 … v2-e007)
- Dark-mode chat app. Left sidebar with app/navigation icons; top-left header **"Chats"**; top-right circular avatar labeled "Chip".
- Conversation thread (newest at bottom):
  - Chip (red/orange bubble): *"Nice — that's the pond test done. You covered the maintenance ask and the pump leaks, which were the two things that mattered. One more Monday task off the board."*
  - Chip (red/orange bubble): *"I have muse installed on my mac via safari's install to dock. It keeps autocorrecting my test, how do I disable that?"*
  - Assistant: *"That's macOS doing it, not Muse. Easiest fix, with the Muse app open and focused: Edit → Spelling and Grammar → uncheck 'Correct Spelling Automatically'. That turns it off just for the Muse dock app. If you want it gone everywhere on the Mac, it's System Settings → Keyboard → Text Input → Edit → turn off 'Correct spelling automatically.'"*
  - Assistant: *"Yeah, your app doesn't have that menu item — Apple moved it. Go system-wide instead. System Settings → Keyboard → Text input → click 'Edit…' → turn off 'Correct spelling automatically.' That covers the Muse dock app too, since its text fields follow the system setting. Only downside is it applies to every app on the Mac, not just Muse."*
  - Assistant: *"Found it — 'Correct spelling automatically' is already off, so that's not your culprit. The one doing it is 'Show inline predictive text' — it's on, and it inserts gray suggestions as you type, which feels exactly like autocorrect. Flip that off and hit Done."*
  - Two small image thumbnails (screenshots) attached mid-thread; unreadable at this resolution.
- Bottom message input bar (`+` icon, text field, voice/send icons). Chip is typing a test message; it grows across frames, demonstrating the autocorrect issue:
  - e001: empty placeholder "This is meeee…"
  - e002: "This is meeee typing and seein|"
  - e003: "This is meeee typing and seeing fit auto|"
  - e004: "This is meeee typing and seeing fit autocorr… You also|"
  - e005: "…You also cabana notice|"
  - e006: "…You also cabana notice t|hee green"
  - e007: "…You also cabana notice t|hee green occasionally" (cursor mid-word in "thee", autocorrect having produced "cabana" from "caban(a)" and green-inked "thee")
- Interaction: Chip types character-by-character; autocorrect visibly substitutes words (e.g. "can also" → "cabana", producing the red-green tinted "thee green").
