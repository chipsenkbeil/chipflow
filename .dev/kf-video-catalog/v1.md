# KanbanFlow walkthrough video v1 — UI surface catalog

**Overall topic:** Timer and reporting workflows in KanbanFlow — starting/stopping a pomodoro timer on a task, the Timer log (period filtering, custom date ranges, print, Excel/CSV export), the Time spent report, the Pomodoro statistics report, then board-layout editing (add column, drag to reorder, column context menu, Edit column dialog), the board Filter panel, and the Reports menu. 26 frames, one every 5 seconds, all viewed.

**Persistent chrome (all frames):** KanbanFlow top bar: "Boards" tab left, board tab "General" (active) with `+` add-board icon, KanbanFlow logo centered, timer readout with play/stop + filter + gear icons, "Menu" (hamburger) right. Board columns: "Work To-do", "Do today", "In progress x/y", "Done", "BACKLOG" vertical divider at far right. Each column header has a green `+` (add task). Bottom pomodoro legend strip: "1 Pomodoro | 2 Pomodoros | 3 Pomodoros | >3 Pomodoros". Done-column tasks are grouped by date ("Today", "Friday, 10 July", "Friday, 26 June", "Thursday, 25 June", "Wednesday, 24 June").
